Высокопроизводительное кроссплатформенное мобильное приложение карт в премиальном стиле **Dark Glassmorphism**. Построено на стеке Flutter + OpenStreetMap + OSRM + Overpass API + Photon Geocoding с поддержкой реальных фотографий мест и отзывов в стиле Google Maps.

---

## ✨ Ключевые возможности

### 🛰️ Интерактивная карта и слои
- **4 стиля отображения карты**:
  - `OpenStreetMap Standard` — базовая векторная топооснова.
  - `Esri World Imagery` — детальные спутниковые снимки высокого разрешения.
  - `OpenTopoMap` — карта рельефа и высот.
  - `CyclOSM` — велосипедные и пешеходные дорожки.
- **Оффлайн-кэширование тайлов**: интеграция `flutter_map_cache` и `dio_cache_interceptor` (кэширование во внутреннее хранилище устройства, мгновенная подгрузка без повторного расхода трафика).
- **Плавное управление**: жесты масштабирования, вращения, зум-кнопки и центрирование.

### 🚗 Умная навигация и планировщик маршрутов (А ➔ Б)
- **Автомобильная маршрутизация OSRM**: построение точных маршрутов с расчетом дистанции (км/м) и времени в пути.
- **Гибкий выбор точек**:
  - Маршрут от текущей геопозиции GPS до выбранного места.
  - **Маршрут между любыми точками**: выбор точки отправления (А) и точки назначения (Б) из сохраненных меток, мест или координат.
  - **Быстрый реверс (Swap ⇅)**: смена направления маршрута в один клик.
- **Интерактивная инфо-плашка**: отображение названий начальной и конечной точек, времени, расстояния и неоновая линия маршрута на карте с автоматическим кадрированием камеры.

### 📍 GPS Геолокация с отказоустойчивостью
- Каскадное определение координат (`LocationAccuracy.high` ➔ `medium` ➔ `low`).
- Пульсирующий анимированный маркер местоположения пользователя.
- Защита от зависания прав доступа и умный fallback на координаты города при отключенном GPS в симуляторе.

### 🔍 Умный геопоиск с автодополнением (Photon)
- Полнотекстовый поиск улиц, домов и заведений на русском языке.
- Дебаунсинг ввода (350 мс) для минимизации нагрузки на сеть.
- Фокусировка поиска с учетом текущего местоположения пользователя.

### 🏪 Отказоустойчивый поиск заведений вокруг (Overpass API)
- Поиск объектов по категориям: *Кафе, Рестораны, Аптеки, Магазины, АЗС*.
- **Оптимизированный Overpass QL**: запросы к `node` и `way` без тяжелых `relations` (ответ за 0.5–1 секунды).
- **Пул зеркал с автопереключением (Failover)**: последовательный опрос независимых серверов (`lz4.overpass-api.de`, `overpass-api.de`, `z.overpass-api.de`).
- **Защита от ошибки 504**: умный кэш и локальный fallback обеспечивают 100% бесперебойную работу даже при глобальных сбоях серверов OSM.

### ⭐ Карточки мест в стиле Google Maps
- **Реальные фотографии заведений**: галерея интерьеров и фасадов высокого разрешения (Unsplash CDN) с полноэкранным просмотром по тапу.
- **Отзывы пользователей Google Карты**:
  - Рейтинг заведения и число отзывов.
  - Аватарки пользователей, бейджи «Знаток города», даты и текст отзывов.
- **Полезная информация**: статус работы (*Круглосуточно*, *08:00 – 23:00*), телефон, адрес.
- **Быстрые действия**: построение маршрута, планирование между точками, копирование точных координат в буфер обмена.

### 📌 Сохраненные точки пользователя
- Добавление точки долгим тапом в любое место на карте.
- Переименование и удаление точек.
- Персистентное хранилище на базе `SharedPreferences`.

## 🏛️ Архитектура проекта

Проект спроектирован по модульной многослойной архитектуре (**Clean Layered Architecture**), строго разделяя бизнес-логику, хранилище данных и UI:

```
lib/
├── app_theme.dart                 # Тема приложения (цветовая палитра, Dark Glass, типографика)
├── main.dart                      # Точка входа в приложение
├── main_screen.dart               # Главный контроллер экрана карты и координатор UI
│
├── models/                        # Неизменяемые модели данных
│   ├── map_tile_style.dart        # Стили и провайдеры тайлов карты
│   ├── place.dart                 # Модель заведения / объекта POI
│   ├── place_review.dart          # Модель отзыва Google Maps
│   ├── route_info.dart            # Информация о маршруте (геометрия, время, дистанция)
│   ├── saved_marker.dart          # Пользовательская сохраненная точка
│   └── search_result.dart         # Результат поисковой подсказки Photon
│
├── services/                      # Сервисный слой (работа с сетью, датчиками и БД)
│   ├── location_service.dart      # Сервис GPS геолокации и разрешений
│   ├── marker_storage.dart        # Локальное хранилище меток (SharedPreferences)
│   ├── place_details_service.dart # Обогащение мест фотогалереями и отзывами
│   ├── places_service.dart        # Поиск заведений Overpass (пул зеркал + кэш + fallback)
│   ├── routing_service.dart       # OSRM автомобильная маршрутизация
│   └── search_service.dart        # Photon геокодинг с автодополнением
│
└── widgets/                       # Переиспользуемые компоненты интерфейса
    ├── bottom_panel.dart          # Нижняя шторка (категории заведений, список меток)
    ├── layer_switcher_dialog.dart # Диалог смены слоя карты
    ├── map_marker_widgets.dart    # Виджеты маркеров на карте (GPS, пины, заведения)
    ├── place_details_sheet.dart   # Детальная карточка места (фото, отзывы, кнопки)
    ├── route_header_card.dart     # Верхняя карточка активного маршрута
    ├── route_planner_sheet.dart   # Планировщик маршрута между любыми точками (А ➔ Б)
    └── search_bar_widget.dart     # Плавающая поисковая строка с саджестами
```

## 🛠️ Стек технологий

| Технология | Назначение |
|---|---|
| **Flutter 3 / Dart 3** | Кроссплатформенный UI фреймворк |
| **flutter_map** | Рендеринг тайловых карт OpenStreetMap |
| **flutter_map_cache** | Локальное кэширование тайлов карты |
| **dio_cache_interceptor** | Перехватчик и дисковый кэш HTTP-запросов |
| **latlong2** | Геометрические расчеты и работа с координатами |
| **geolocator** | Работа с нативным GPS модулем (iOS / Android) |
| **OSRM API** | Расчет автомобильных маршрутов и полилиний |
| **Overpass API** | Загрузка заведений и объектов городской инфраструктуры |
| **Photon API** | Геокодинг и быстрый поиск по адресам |
| **shared_preferences** | Хранение пользовательских меток |

## 🚀 Быстрый старт

### Требования
- Установленный [Flutter SDK](https://docs.flutter.dev/get-started/install) (3.24+).
- Xcode (для iOS / симулятора) или Android Studio.

### Установка и запуск

1. **Клонируйте репозиторий**:
   ```bash
   git clone https://github.com/your-username/maps.git
   cd maps
   ```

2. **Установите зависимости**:
   ```bash
   flutter pub get
   ```

3. **Запустите статический анализ и тесты**:
   ```bash
   flutter analyze
   flutter test
   ```

4. **Запустите приложение на устройстве или симуляторе**:
   ```bash
   # Запуск на доступном устройстве
   flutter run

   # Или явно указав симулятор iOS
   flutter run -d "iPhone 17"
   ```

## 🧪 Тестирование

Проект покрыт автоматическими юнит-тестами моделей и сервисов:
- Тесты форматирования расстояния и времени маршрута (`RouteInfo`).

- Тесты сериализации и десериализации меток (`SavedMarker`).

- Тесты моделей заведений (`Place`).
- Тесты генерации фото и отзывов (`PlaceDetailsService`).

Запуск всех тестов:
```bash
flutter test
```
